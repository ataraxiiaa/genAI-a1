# IEEE Technical Report Compilation Guide

This folder contains the complete technical report written in the style of a research paper in standard IEEE format (`IEEEtran.cls`).

## File Structure
- `main.tex`: The primary LaTeX research paper document.
- `IEEEtran.cls`: Official IEEE Transactions LaTeX document class file (included locally so the project is completely self-contained).
- `references.bib`: Complete BibTeX bibliography with full citations.
- `../ARCHITECTURE_EXPLANATION_SCRIPTS.md`: Plain-language presentation scripts for all four task architectures.
- `figures/`: All 10 high-resolution publication figures and qualitative comparison grids:
  - `fig_pipeline_architecture.png` (Unified multi-task architecture and deployment)
  - `fig_training_curves.png` (4-panel convergence plot for all 4 tasks)
  - `fig_confusion_matrix.png` (Official-test routing confusion matrix on 36,690 cases)
  - `fig_moe_gating_distribution.png` (Routing weights & global expert load balance)
  - `fig_optuna_study.png` (21 logged trials and $\lambda_{L1}$ values)
  - `fig_cgan_qualitative_grid.png` (FS2K qualitative grid across Styles 1, 2, and 3)
  - `fig_app_architecture.png` (Repository application architecture)
  - `fig_moe_visual_samples.png` (Soft MoE expert visual restoration comparisons)
  - `fig_stitch_design.png` (Google Stitch interactive studio canvas design)
  - `fig_stitch_visionstudio_generated.png` (Live desktop screen generated via Stitch MCP)
  - `visionstudio_stitch.html` (Original HTML/Tailwind CSS generated by Stitch)

## How to Compile

### Option 1: Overleaf (Recommended for Instant Compilation)
1. Select the `report/` folder (or compress the contents of `report/` into a `.zip` archive).
2. Go to [Overleaf](https://www.overleaf.com), click **New Project** > **Upload Project**, and select the `.zip`.
3. Set the compiler to **pdfLaTeX** (default) and compile `main.tex`.

### Option 2: Local Command Line (TeX Live / MiKTeX / MacTeX)
Run the standard LaTeX compilation sequence from within the `report` directory:
```bash
cd report
pdflatex main
bibtex main
pdflatex main
pdflatex main
```
This produces `main.pdf` with all cross-references, equations, tables, figures, and bibliographic citations correctly resolved.
